# Sriprajna Portfolio — GitHub Pages Build

This ZIP is prepared for the root user site at `https://sriprajna.github.io/`.

## Publish

1. Open the `sriprajna.github.io` repository on GitHub.
2. Upload **the contents of this ZIP** to the repository root, not the containing folder.
3. Commit the files to the branch used by GitHub Pages (normally `main`).
4. In **Settings → Pages**, select **Deploy from a branch**, `main`, and `/ (root)`.
5. Wait for the Pages workflow to finish, then open `https://sriprajna.github.io/`.

## Included

- Production portfolio HTML, CSS, and JavaScript
- `404.html` fallback for direct links to portfolio work samples
- Local copies of the two interactive HTML dashboard samples
- Learning analytics smart-art route
- Recruiter guide and project thumbnails
- Downloadable Northstar case-study package

The portfolio uses fictional dashboard data. Northstar AI-style insights are deterministic and simulated, not a live AI integration.
